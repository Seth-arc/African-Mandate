# African Mandate: Sahel Arena — Trailer Image Prompts
**Format:** Grok Imagine / AI video generation prompts, one per 10-second segment
**Total shots:** 11 (105-second trailer + 5-second closing card)
**Palette rule applied to all shots:** Desaturated earth tones — ochre, sand, ash, deep brown, muted olive. Amber/gold used only for light sources and UI elements. No saturated colours. No Western military uniforms. No heroic framing.

---

## GLOBAL STYLE REFERENCE
*Include this as a suffix on every prompt for visual consistency:*
> cinematic 35mm film grain, desaturated earth tones, muted olive and ochre palette, soft dust haze in atmosphere, golden hour side-lighting or harsh overhead midday sun, photojournalist documentary aesthetic, aspect ratio 16:9, no text overlays

## GENERATION TIPS

**For Grok Imagine (static images → video tools like Runway/Sora):**
- Generate at 1792×1024 or 2048×1152 for 16:9
- Request "photorealistic", "cinematic", "documentary photography" style tags
- Add `--ar 16:9` if using Midjourney syntax

**For video motion (Runway Gen-3 / Sora / Kling):**
- Use the static image as a starting frame
- Motion prompts: "extremely slow camera drift", "barely perceptible zoom", "static hold with ambient dust movement"
- Keep motion duration 3–5 seconds per clip and assemble in editing software

**Colour grade applied in post:**
- Reduce saturation -25%
- Push shadows toward deep brown (not blue-black)
- Add subtle warm amber tint to highlights
- Film grain overlay at ~12% opacity
